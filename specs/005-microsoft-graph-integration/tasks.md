## Implementation strategy

Each portion is one reviewable commit. Portion 1 adds a crate nothing uses
yet, portion 2 changes shapes without behaviour, portion 3 adds a request
nothing calls yet, so Mailbag's behaviour is unchanged until portion 4. Live
acceptance happens once, at the end, on the maintainer's account.
